The project adapts the existing DiffCR conditional diffusion model to
LISS-IV satellite imagery. The user has already implemented and trained

replacement project. Preserve the original implementation, dataset,
scripts, notebooks, and checkpoint.

2.  WHAT THE PAPER DOES

-   Uses paired cloudy and clear satellite images.
-   Cloudy imagery conditions the reconstruction; clear imagery is the
    target.
-   Uses a conditional diffusion framework and direct clean-image (x0)
    prediction.
-   Architecture includes condition encoder, time encoder, and denoising
    autoencoder with TCFBlocks.
-   The paper describes patch-based training. For SEN12MS-CR it
    discusses georeferenced/orthorectified, synchronized pairs and
    256x256 patches with 50% overlap.

The paper does NOT require: - A separate cloud-detection model. - A
perfect cloud mask. - SIFT/RANSAC registration. - A cloud mask as a
required DiffCR input. - Pix2Pix/PatchGAN or a cloud-mask pretraining
stage.

A cloud mask is optional for registration assistance or cloud-region
evaluation. It is not a required DiffCR input. Do not waste time
perfecting the heuristic cloud mask.

3.  OUR LISS-IV ADAPTATION Bands:

-   BAND2 = Green
-   BAND3 = Red
-   BAND4 = NIR

DiffCR model input: 6 channels (3 cloudy + 3 noisy clear channels).
DiffCR output: 3-channel predicted clear image. Existing normalization:
2 * (x / 1023) - 1, nominal range [-1, 1].

Radiometric ranges and scaling for the new LISS-IV cloudy/clear products
have NOT been fully verified. Do not assume 1023 is correct for both
without checking.

4.  PROPOSED EXPERIMENT / NOVELTY HYPOTHESIS Proposed total loss:
    L_total = lambda1 * L1 + lambda2 * L_SAM + lambda3 * L_Spectral

-   L1: pixel reconstruction loss.
-   SAM: Spectral Angle Mapper loss.
-   Spectral: inter-band spectral consistency loss.

This is a hypothesis, not proven novelty or guaranteed improvement. It
needs a literature review, ablation study, and comparison against the
original DiffCR loss and baseline. Do not claim novelty or improvement
before evidence.

11. ALIGNMENT: DISTINGUISH FOUR THINGS
12. Geographic overlap: whether the two scenes cover a common area.
13. CRS/grid reprojection: common CRS, dimensions, and pixel grid.
14. Residual pixel registration: whether the same ground features occupy
    corresponding pixels.
15. Common valid footprint: whether both images are valid at the same
    locations.

Pair1 has completed geospatial reprojection to a common grid. However,
matching CRS/dimensions/transform alone does NOT prove pixel-level
ground-feature correspondence. Paired pixel-wise supervised training
requires spatial correspondence.
